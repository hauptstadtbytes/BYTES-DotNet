# Breaking Changes
Alles, was stark verändert wurde. Alte Codeteile, die nicht migriert wurden, etc.

## FTP
-> nicht migriert. 
Empfehlung: Benutzen von FluentFTP für FTP, SSHnet für SFTP. Beispiele für die Benutzung sind in FtpCLI, SftpCLI

## LDAP
-> nicht migriert
Empfehlung: Benutzen von Novell. Beispiel für die Benutzung ist in LDAPCLI.

## Http
-> nicht migriert (HttpClient)
Empfehlung: Benutzen der neuen .Net Klasse "HttpClient". Verwendungsbeispiel in HttpClientCLI.
