# Registry

To work with the Windows registry, BYTES.NET.Windows offers the Registry namespace. Part of the namespace is the RegistryNode class.

## RegistryNode.cs
The class is a wrapper for the .net RegistryKey class. It offers functionality to store keys as RegistryNodes, as well as creating, updating and deleting keys, as well as searching for keys.

## How to use
An example of how to use the class is in RegistryCLI.
